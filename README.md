# KSF Electromechanical Works

The KSF Electromechanical Works L.L.C. website, built with TanStack Start,
React, and Vite.

## Development

Install dependencies and start the local development server:

```sh
npm install
npm run dev
```

## Production

Create and preview a production build:

```sh
npm run build
npm run preview
```

## Routes

- `/` — Home
- `/about` — About KSF
- `/services` — Services
- `/contact` — Contact and enquiries
